# Service manual and interchangeable-parts references (cheat sheet)

**Status:** Starting list compiled from general knowledge. The sandbox had no network access, so **no link was checked**. Verify each site, its current URL, pricing and terms before use. Manual content is copyrighted and is not reproduced in this repo. Use these as sources to cite, with edition and retrieval date (see SERVICE-MANUAL.md).

## 1. Professional multi-make service information (subscription)

| Site | Typical use |
| --- | --- |
| alldata.com | OEM repair procedures, specs, TSBs, wiring (domestic and import) |
| mitchell1.com (ProDemand) | Repair, labour, maintenance schedules, wiring |
| identifix.com | Diagnostic fixes and technician-reported repairs |

## 2. OEM service-information portals (domestic first; paid access, short-term subscriptions usually available)

| Make | Portal |
| --- | --- |
| Ford / Lincoln | motorcraftservice.com |
| GM | acdelcotechconnect.com |
| Stellantis (Chrysler, Dodge, Jeep, Ram) | techauthority.com |
| Toyota / Lexus | techinfo.toyota.com |
| Honda / Acura | techinfo.honda.com |
| Hyundai | hyundaitechinfo.com |

Other makes: search "<make> technical information system" and confirm it is the manufacturer's own site.

## 3. Chassis, brakes, steering and suspension

- OEM portals above are the authority for torque, alignment and brake specs.
- Haynes / Chilton (haynes.com): consumer and shop repair manuals; many public libraries offer online Chilton-style access.
- Heavy-duty/body-builder chassis: use the chassis OEM's body-builder or service portal.

## 5. Interchangeable parts and part-number lookup

| Source | Use |
| --- | --- |
| Hollander Interchange (hollanderinterchange.com) | Industry reference for used/recycled-part interchange |
| car-part.com | Used-part locator using interchange data |
| rockauto.com | Catalogue by vehicle with cross-referenced aftermarket numbers |
| Dealer parts catalogues (OEM) | Authoritative part numbers and supersessions |

Always confirm interchange against VIN, build date and option codes. Record the source for each substitution.

## 6. Canadian access and regulation

- Automotive Industries Association of Canada (aiacanada.com): right-to-repair and service-information access (CASIS).
- Transport Canada (tc.canada.ca): Canada Motor Vehicle Safety Standards and recalls.
- Provincial ministries of transportation: inspection and licensing rules.

## 7. Cheat-sheet workflow

1. Decode VIN, record build date and options.
2. Pull specs and procedure from the OEM portal.
3. Look up the part number and supersession in the OEM catalogue.
4. Check interchange in a secondary source, then record both.
5. Cite source, edition and retrieval date in the job report.
